### 📌 نظرة عامة على المشروع
**رُقي للعطور الفاخرة** هو مشروع موقع إلكتروني تجريبي لمتجر عطور فاخر متكامل، تم تصميمه وتطويره لاستعراض المهارات المتقدمة في تطوير الواجهات الأمامية (Frontend Development) وتصميم تجربة المستخدم (UI/UX) في مجال المتاجر الإلكترونية الفاخرة.

يعكس الموقع هوية علامة تجارية تجريبية للعطور تجمع بين تراث العطور الشرقية الأصيلة (كالعود الملكي والعنبر والمسك) وأحدث اتجاهات الأناقة والبساطة العصرية.

> هذا المشروع **تجريبي ومخصص لأغراض عرض الأعمال (Portfolio)**. جميع المنتجات، الأسعار، التقييمات، معلومات الاتصال والعناوين هي بيانات افتراضية لا تمثل علامات تجارية أو شركات حقيقية. لا توجد عمليات دفع أو شراء حقيقية على الموقع.

### ✨ المميزات الرئيسية
- **دعم دوال ثنائية اللغة (العربية والإنجليزية)**: تبديل فوري بين العربية والإنجليزية مع ترجمة شاملة لجميع العناصر والصفحات.
- **دعم اتجاهات الكتابة (RTL / LTR)**: دعم تلقائي للاتجاه من اليمين إلى اليسار (RTL) باللغة العربية، ومن اليسار إلى اليمين (LTR) باللغة الإنجليزية.
- **كتالوج عطور فاخر تفاعلي**: عرض بطاقات المنتجات مع تفاصيل الهرم العطري (افتتاحية العطر، قلب العطر، قاعدة العطر)، اختيار الحجم (50مل، 100مل، 200مل)، والمكونات.
- **تصفية وبحث متقدم**: بحث سريع حسب اسم العطر أو المكونات، تصفية حسب العائلات العطرية، شريط تحكم بنطاق السعر، وخيارات الترتيب متعددة.
- **حقيبة تسوق تفاعلية**: إضافة العطور وتعديل الكميات وحساب الإجمالي مع حفظ حالة الحقيبة في **التخزين المحلي (LocalStorage)**.
- **إتمام طلب تجريبي (Demo Checkout)**: محاكاة تفاعلية كاملة لعملية الدفع وإصدار الفاتورة التجريبية.
- **تصميم تجاوبي متكامل (Responsive Design)**: تجربة تسوق سلسة ومبهرة على جميع الشاشات والهواتف الذكية.

### 📄 الصفحات والتركيب
1. **الصفحة الرئيسية (`/`)**: بنر ترحيبي فاخر، العطور الأكثر مبيعاً، فلسفة العلامة، العائلات العطرية، الهرم العطري، وآراء العملاء.
2. **صفحة المتجر (`/shop`)**: الكتالوج الكامل، البحث، التصفية حسب الفئة والسعر، والترتيب.
3. **صفحة تفاصيل العطر (`/shop/[id]`)**: معرض الصور، الهرم العطري، المكونات الرئيسية، خيارات الحجم، وإضافة للحقيبة.
4. **صفحة حقيبة التسوق (`/cart`)**: إدارة العناصر، حساب المجموع، زر تفريغ الحقيبة، وزر إتمام الطلب التجريبي.
5. **صفحة عن العلامة (`/about`)**: قصة التأسيس، الحرفية العطرية، وقيم العلامة (الجودة، الأناقة، الإبداع، التميز).
6. **صفحة تواصل معنا (`/contact`)**: نموذج التواصل التجريبي، بيانات الاتصال، وساعات العمل والأسئلة الشائعة.

## 🇬🇧 English Section

### 📌 Project Overview
**Rouqi Perfumes** (*رُقي للعطور الفاخرة*) is a premier, full-featured luxury fragrance e-commerce web application demo designed to showcase high-end frontend architecture, rich UI/UX aesthetics, and smooth shopping user flows.

The website represents a fictional haute parfumerie brand combining authentic Arabian perfume heritage with contemporary European minimalist elegance.

> ⚠️ **IMPORTANT NOTICE:**  
> This is a **fictional portfolio project** built exclusively for demonstration and educational purposes. All perfumes, prices, customer reviews, addresses, and company information are entirely fictional. No real payments or orders are processed.

---

### ✨ Key Features
- **Bilingual Support (Arabic & English)**: Instant locale toggle with complete translation coverage across all pages.
- **RTL / LTR Dynamic Layouts**: Native Right-To-Left direction for Arabic (default) and Left-To-Right direction for English.
- **Rich Olfactory Product Catalog**: Detailed fragrance listings featuring notes pyramids (Top, Heart, Base), volume options, and ingredients.
- **Interactive Search & Filtering**: Filter perfumes by category (Oriental, Men, Women, Exclusive), price range slider, scent family, and dynamic sorting.
- **Client-Side Shopping Cart**: Full shopping bag management with volume selection, item quantity controls, line totals, and **LocalStorage** state persistence.
- **Interactive Demo Checkout**: Simulated checkout workflow complete with shipping details input, payment method selection, and order confirmation receipt modal.
- **Responsive & Mobile-First Design**: Optimized touch controls, mobile drawer navigation, and fluid layouts for smartphones, tablets, and desktops.

---

### 🛠️ Technology Stack
- **Framework**: Next.js 16+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 (Custom Luxury Theme Tokens)
- **Animations**: Framer Motion
- **Icons**: Lucide Icons (`lucide-react`)
- **State Management**: React Context API (`CartContext`, `LanguageContext`)

### 🚀 Installation & Running / التثبيت والتشغيل

```bash

cd rouqi-perfumes
```
